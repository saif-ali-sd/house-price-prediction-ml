# house-price-prediction-ml
# 🏠 House Price Prediction using Machine Learning

An end-to-end Machine Learning project that predicts house prices based on property features such as size, location, construction year, basement area, and more.

This project demonstrates the full ML workflow:
Data exploration → Cleaning → Feature Engineering → Model Training → Evaluation → Prediction.

---

## 📊 Dataset
The dataset contains 13 features including:
- LotArea
- BldgType
- OverallCond
- YearBuilt
- Exterior1st
- TotalBsmtSF
- SalePrice (target)

---

## 🤖 Models Used
- Support Vector Regression (SVR)
- Random Forest Regressor
- Linear Regression

### 🏆 Best Model
Support Vector Regression (SVR)  
Achieved **~18% Mean Absolute Percentage Error (MAPE)**

---

## 📁 Project Structure
notebooks/ → Jupyter notebooks (full ML pipeline)

data/ → Raw & processed datasets

models/ → Trained ML model

## 🚀 How to Run the Project

1️⃣ Clone the repository
git clone https://github.com/saif-ali-sd/house-price-prediction-ml

cd house-price-prediction-ml

2️⃣ Install dependencies

pip install -r requirements.txt

3️⃣ Open Jupyter Notebook

jupyter notebook

4️⃣ Run:

notebooks/main.ipynb


This will execute the full pipeline automatically.
